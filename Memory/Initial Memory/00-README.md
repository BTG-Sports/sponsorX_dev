# SponsorX — Memory Backup

This `Memory/` folder is the in-repo, human-readable record of the SponsorX project's knowledge and every task performed.

## How this folder is organized

- **`Initial Memory/`** — the baseline snapshot: all project knowledge, rules, decisions, and findings as of the project's starting point (created **2026-09-10**). Update only when foundational facts change.
- **`YYYY-MM-DD/`** — one dated subfolder per day work is done, logging the tasks completed that day. If the dated folder doesn't exist yet, it is created before logging.

## The standing rule

> After completing **any task** on SponsorX, update memory and back it up here, under a subfolder named for the date the task was done (`YYYY-MM-DD`). Create the dated subfolder first if it doesn't exist.
