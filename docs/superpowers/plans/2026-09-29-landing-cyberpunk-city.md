# Landing cyberpunk city — implementation plan (P1-ART-09)

Spec: `docs/superpowers/specs/2026-09-29-landing-cyberpunk-city-design.md`.
Working assets (extracted from the unitypackage) live in the session scratchpad
under `cyber/`; nothing from there is committed except the pipeline outputs.

## Shared contracts (done first, by hand)

- `frontend/src/lib/city/types.ts` — Placement, Layer, venue specs, CityLayout, KitManifest.
- `frontend/src/lib/city/collision.ts` — world AABB from placement + manifest, `findOverlaps`, `outsideSite`.
- `frontend/src/lib/city/palette.ts` — the mesh subset the city uses; export list + allow-list.
- `frontend/src/lib/city/kit-manifest.json` — per-mesh bounds/tris/materials (regenerated by the pipeline from LOD0 only).
- `frontend/src/lib/city/layout.ts` — `getCityLayout(tier)`; stub first, real site plan second.

## Tasks (A–C run in parallel; D depends on all)

**A. Asset pipeline** — `frontend/scripts/city-kit/` (Node + Blender 4.5 headless), `npm run city:kit -w @sponsorx/frontend`.
   extract (tar list file, `--force-local`) → resolve (`.mat` → texture roles; prefab slot order; alias table) →
   export (Blender: LOD0 per palette mesh, LOD2 as `<id>__lod` where `lod: true`, drop hulls/LOD1;
   Principled materials from B/N/ORM/E/O; TGAs pre-scaled to 2K; one glTF, shared images) →
   optimize (gltf-transform: dedup, prune, per-palette texture caps → WebP, meshopt) → `city-kit.glb`, `city-kit-lite.glb`,
   `env.hdr`, regenerated manifest. Report sizes, tris, unresolved materials.

**B. Scene shell** — `frontend/src/components/city/`: `city-backdrop.tsx` (client gate, dynamic ssr:false inside the
   client boundary, poster, fade-in, scrim, `?orbit=1`, FPS watchdog), `city-scene.tsx` (Canvas, lights, fog,
   environment, post desktop-only, fixed viewpoint / orbit), `kit-instances.tsx` (useGLTF + meshopt → one
   InstancedMesh per mesh/primitive from placements, `__lod` fallback, emissive boost), `city-world.tsx`,
   `city-poster.tsx`; `frontend/src/lib/city/capability.ts` (+ test). Page: `<CityBackdrop />` first child of `(public)/page.tsx`.

**C. Procedural venues** — `frontend/src/components/city/venues/`: basketball court (surface + lines + hoops),
   soccer pitch (turf + lines + goals), baseball field (quarter-disc grass, dirt diamond, paths, mound, bases),
   pedestal (octagonal tiers + emissive rings), skyscraper extras (crown ring, warning light), gantry screen
   (posts, beam, "SPONSORX" emissive canvas), cables (merged tubes). Canvas textures only, MeshStandardMaterial only.

**D. Layout, tests, integration, verification** (by hand)
   1. `layout.ts` real site plan: ground grids, boulevard, plaza, three venue lots (kit fences, masts, benches,
      gates), commercial/residential blocks (storefront kits, apartment blocks, rooftop dressing), forecourt,
      skyscraper cluster, seeded city fill, street furniture, drones, cables; `LANDMARKS`; venue collision boxes.
   2. `frontend/tests/city-collision.test.ts` (unit) and `frontend/tests/city-layout.test.ts` (no overlaps outside kits,
      inside site, palette-only meshes, venue dimensions, pedestal at plaza centre, skyscraper ≥ 100 m, fill passes).
   3. Run A's pipeline output through the scene; review at `/?orbit=1`; tune emissive/fog/lights.
   4. Stop the dev server → `npm run build` → restart; frontend vitest; eslint; Playwright smoke on `/`.
   5. Adversarial review workflow (layout data vs spec, collision math, R3F correctness, perf budget).
   6. Board: raise `P1-ART-09` (xlsx row + phase doc), Memory/2026-09-29 log, commit.
